# DORO Solutions Website

Static website prepared for GitHub and Cloudflare Pages.

## Files
- `index.html` — Home page
- `styles.css` — visual styling and responsive layout
- `script.js` — 3-slide carousel and mobile menu
- `assets/` — logo and the three approved carousel images

## Cloudflare Pages
This is a static site. No build command is required.
Set the output/root directory to the repository root.
